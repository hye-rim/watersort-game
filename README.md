# 물 정렬

병 사이로 물을 따라 같은 색끼리 한 병에 모으는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 병을 눌러 든 다음, 물을 부을 병을 누른다. 맨 위 색이 같거나 빈 병에만 부을 수 있고, 위에 이어진 같은 색이 한꺼번에 넘어간다
- 모든 병이 한 가지 색으로 가득 차면 클리어. 레벨이 오를수록 색이 늘어난다 (3색 → 최대 12색)
- 되돌리기는 마음껏, 빈 병 추가는 한 판에 1번, 힌트는 한 판에 3번
- 판은 매번 새로 만들고, 풀 수 있는 판만 낸다 (풀이기로 확인). 힌트도 같은 풀이기가 다음 수를 알려 준다
- 진행한 레벨은 브라우저에 저장된다

`index.html` 을 그대로 열면 된다. 규칙·풀이는 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력은 `game.js`.
